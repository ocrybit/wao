# Vibe Engineer's Guide to AO Development

Welcome to the world of AO development! This guide is designed for complete beginners - you don't need any programming experience. We'll use Claude Code as your AI pair programmer to build real applications on the AO hypercomputer.

## What You'll Learn

By the end of this guide, you'll be able to:
- Set up a complete development environment
- Build 3 types of AO applications (Counter, Token, Messenger)
- Create custom HyperBEAM devices
- Test everything locally before deploying

## What is AO?

AO is a decentralized hypercomputer built on Arweave. Think of it as a global computer where:
- **Processes** are like apps that run forever
- **Messages** are how you interact with processes
- **Handlers** are functions that respond to messages
- **State** is the memory that persists between messages

## What is WAO?

WAO (Web AO) is a JavaScript SDK that makes AO development fast and easy. It includes:
- **In-memory testing** - Test your apps 1000x faster than on mainnet
- **HyperBEAM integration** - Test with real beta3 infrastructure locally
- **Simple APIs** - Write less code, do more

## Part 2: Your First AO App - Counter

The Counter app teaches you the fundamentals: handlers, state, and messages.

### What We're Building

A simple counter that can:
- Get the current count
- Increment (+1)
- Decrement (-1)
- Add any number
- Reset to zero

### Step 1: Write the Lua Script

Ask Claude:

```
Create a counter.lua file with handlers for Get, Inc, Dec, Add, and Reset
```

Create `counter.lua`:

```lua
--[[
  Counter App
  A simple stateful counter demonstrating AO handler patterns
]]

-- State: the current count
local count = 0

-- Get: return current count (read-only)
Handlers.add("Get", "Get", function(msg)
  msg.reply({ Data = tostring(count) })
end)

-- Inc: increment by 1
Handlers.add("Inc", "Inc", function(msg)
  count = count + 1
  msg.reply({ Data = tostring(count) })
end)

-- Dec: decrement by 1
Handlers.add("Dec", "Dec", function(msg)
  count = count - 1
  msg.reply({ Data = tostring(count) })
end)

-- Add: add a specific number
Handlers.add("Add", "Add", function(msg)
  local value = tonumber(msg.Tags.Value) or 0
  count = count + value
  msg.reply({ Data = tostring(count) })
end)

-- Reset: set count back to 0
Handlers.add("Reset", "Reset", function(msg)
  count = 0
  msg.reply({ Data = tostring(count) })
end)

-- Info: return app information
Handlers.add("Info", "Info", function(msg)
  msg.reply({
    Data = "Counter App v1.0",
    Tags = {
      Count = tostring(count),
      Version = "1.0"
    }
  })
end)
```

### Understanding the Code

Let's break down what each part does:

```lua
local count = 0
```
This creates a **state variable**. It starts at 0 and persists between messages.

```lua
Handlers.add("Inc", "Inc", function(msg)
```
This registers a **handler** named "Inc" that triggers when a message has `Action = "Inc"`.

```lua
msg.reply({ Data = tostring(count) })
```
This sends a **response** back to whoever sent the message.

## Part 3: Building a Token - The ao Standard

The Token app implements the official ao token specification. This is how real tokens work on AO.

### What We're Building

A complete token with:
- Balances for each holder
- Transfers between accounts
- Minting (creating new tokens)
- Burning (destroying tokens)
- Allowances (approve others to spend)

### Step 1: Write the Token Script

Ask Claude:

```
Create token.lua implementing the ao Standard Token Specification with Transfer, Balance, Mint, Burn, and Allowance handlers
```

Create `token.lua`:

```lua
--[[
  Token App - ao Standard Token Specification
  Implements: Info, Balance, Balances, Transfer, Mint, Burn, Approve, Allowance, Transfer-From
]]

local bint = require('.bint')(256)  -- Big integers for precise math

-- Token Configuration
Name = Name or "My Token"
Ticker = Ticker or "MTK"
Logo = Logo or "optional-arweave-tx-id"
Denomination = Denomination or 12  -- Decimal places
TotalSupply = TotalSupply or bint(0)

-- State Tables
Balances = Balances or {}      -- { [address] = amount }
Allowances = Allowances or {}  -- { [owner] = { [spender] = amount } }

-- The process owner (who can mint)
Owner = Owner or ao.id

-- Helper: Check if value is positive
local function isPositive(value)
  return bint.__lt(0, bint(value))
end

-- Helper: Get balance (returns "0" if not found)
local function getBalance(addr)
  return Balances[addr] or "0"
end

-- Info: Return token metadata
Handlers.add("Info", "Info", function(msg)
  msg.reply({
    Tags = {
      Name = Name,
      Ticker = Ticker,
      Logo = Logo,
      Denomination = tostring(Denomination),
      ["Total-Supply"] = tostring(TotalSupply)
    }
  })
end)

-- Balance: Get balance of an address
Handlers.add("Balance", "Balance", function(msg)
  local target = msg.Tags.Target or msg.From
  local balance = getBalance(target)

  msg.reply({
    Data = balance,
    Tags = {
      Balance = balance,
      Target = target,
      Ticker = Ticker
    }
  })
end)

-- Balances: Get all balances
Handlers.add("Balances", "Balances", function(msg)
  msg.reply({
    Data = require('json').encode(Balances)
  })
end)

-- Transfer: Send tokens to another address
Handlers.add("Transfer", "Transfer", function(msg)
  local recipient = msg.Tags.Recipient
  local quantity = msg.Tags.Quantity

  -- Validate inputs
  assert(recipient, "Recipient is required")
  assert(quantity, "Quantity is required")
  assert(isPositive(quantity), "Quantity must be positive")

  local senderBalance = bint(getBalance(msg.From))
  local transferAmount = bint(quantity)

  -- Check sufficient balance
  assert(bint.__le(transferAmount, senderBalance), "Insufficient balance")

  -- Perform transfer
  Balances[msg.From] = tostring(bint.__sub(senderBalance, transferAmount))
  Balances[recipient] = tostring(bint.__add(bint(getBalance(recipient)), transferAmount))

  -- Send notifications
  -- Debit notice to sender
  ao.send({
    Target = msg.From,
    Action = "Debit-Notice",
    Tags = {
      Recipient = recipient,
      Quantity = quantity
    }
  })

  -- Credit notice to recipient
  ao.send({
    Target = recipient,
    Action = "Credit-Notice",
    Tags = {
      Sender = msg.From,
      Quantity = quantity
    }
  })

  msg.reply({
    Tags = {
      Status = "Success",
      ["New-Balance"] = Balances[msg.From]
    }
  })
end)

-- Mint: Create new tokens (owner only)
Handlers.add("Mint", "Mint", function(msg)
  assert(msg.From == Owner, "Only owner can mint")

  local quantity = msg.Tags.Quantity
  local recipient = msg.Tags.Recipient or Owner

  assert(quantity, "Quantity is required")
  assert(isPositive(quantity), "Quantity must be positive")

  local mintAmount = bint(quantity)

  -- Add to recipient balance
  Balances[recipient] = tostring(bint.__add(bint(getBalance(recipient)), mintAmount))

  -- Update total supply
  TotalSupply = bint.__add(TotalSupply, mintAmount)

  msg.reply({
    Tags = {
      Status = "Success",
      ["Minted-To"] = recipient,
      Quantity = quantity,
      ["New-Balance"] = Balances[recipient],
      ["Total-Supply"] = tostring(TotalSupply)
    }
  })
end)

-- Burn: Destroy tokens
Handlers.add("Burn", "Burn", function(msg)
  local quantity = msg.Tags.Quantity

  assert(quantity, "Quantity is required")
  assert(isPositive(quantity), "Quantity must be positive")

  local burnAmount = bint(quantity)
  local balance = bint(getBalance(msg.From))

  assert(bint.__le(burnAmount, balance), "Insufficient balance to burn")

  -- Subtract from balance
  Balances[msg.From] = tostring(bint.__sub(balance, burnAmount))

  -- Update total supply
  TotalSupply = bint.__sub(TotalSupply, burnAmount)

  msg.reply({
    Tags = {
      Status = "Success",
      Quantity = quantity,
      ["New-Balance"] = Balances[msg.From],
      ["Total-Supply"] = tostring(TotalSupply)
    }
  })
end)

-- Approve: Allow another address to spend your tokens
Handlers.add("Approve", "Approve", function(msg)
  local spender = msg.Tags.Spender
  local quantity = msg.Tags.Quantity

  assert(spender, "Spender is required")
  assert(quantity, "Quantity is required")

  -- Initialize allowances table for owner if needed
  Allowances[msg.From] = Allowances[msg.From] or {}
  Allowances[msg.From][spender] = quantity

  msg.reply({
    Tags = {
      Status = "Success",
      Spender = spender,
      Allowance = quantity
    }
  })
end)

-- Allowance: Check spending allowance
Handlers.add("Allowance", "Allowance", function(msg)
  local owner = msg.Tags.Owner or msg.From
  local spender = msg.Tags.Spender

  assert(spender, "Spender is required")

  local allowance = "0"
  if Allowances[owner] then
    allowance = Allowances[owner][spender] or "0"
  end

  msg.reply({
    Data = allowance,
    Tags = {
      Owner = owner,
      Spender = spender,
      Allowance = allowance
    }
  })
end)

-- Transfer-From: Spend tokens on behalf of another (requires approval)
Handlers.add("Transfer-From", "Transfer-From", function(msg)
  local owner = msg.Tags.Owner
  local recipient = msg.Tags.Recipient
  local quantity = msg.Tags.Quantity

  assert(owner, "Owner is required")
  assert(recipient, "Recipient is required")
  assert(quantity, "Quantity is required")
  assert(isPositive(quantity), "Quantity must be positive")

  -- Check allowance
  local allowance = bint((Allowances[owner] or {})[msg.From] or "0")
  local transferAmount = bint(quantity)

  assert(bint.__le(transferAmount, allowance), "Insufficient allowance")

  -- Check owner's balance
  local ownerBalance = bint(getBalance(owner))
  assert(bint.__le(transferAmount, ownerBalance), "Insufficient balance")

  -- Perform transfer
  Balances[owner] = tostring(bint.__sub(ownerBalance, transferAmount))
  Balances[recipient] = tostring(bint.__add(bint(getBalance(recipient)), transferAmount))

  -- Reduce allowance
  Allowances[owner][msg.From] = tostring(bint.__sub(allowance, transferAmount))

  msg.reply({
    Tags = {
      Status = "Success",
      Owner = owner,
      Recipient = recipient,
      Quantity = quantity
    }
  })
end)
```

## Part 4: Building a Messenger - Inter-Process Communication

The Messenger app demonstrates how AO processes communicate with each other using the `push@1.0` device.

### What We're Building

A messaging system where:
- Users can register with a name
- Add contacts (other processes)
- Send messages between processes
- Broadcast to all contacts
- Ping/pong for health checks

### Step 1: Write the Messenger Script

Ask Claude:

```
Create messenger.lua with Register, AddContact, SendMessage, GetInbox, Broadcast, and Ping handlers using Send() for inter-process messaging
```

Create `messenger.lua`:

```lua
--[[
  Messenger App - Inter-Process Communication
  Uses push@1.0 device via Send() for message delivery between processes
]]

-- State
Name = Name or "Anonymous"
Contacts = Contacts or {}      -- { [pid] = name }
Inbox = Inbox or {}            -- Received messages
Outbox = Outbox or {}          -- Sent messages
MessageCount = MessageCount or 0

-- Register: Set your display name
Handlers.add("Register", "Register", function(msg)
  local newName = msg.Tags.Name
  assert(newName and #newName > 0, "Name is required")

  Name = newName

  msg.reply({
    Tags = {
      Status = "Success",
      Name = Name
    }
  })
end)

-- WhoAmI: Get your registration info
Handlers.add("WhoAmI", "WhoAmI", function(msg)
  msg.reply({
    Data = Name,
    Tags = {
      Name = Name,
      ProcessId = ao.id,
      MessageCount = tostring(MessageCount)
    }
  })
end)

-- AddContact: Add another process as a contact
Handlers.add("AddContact", "AddContact", function(msg)
  local contactPid = msg.Tags.Contact
  local contactName = msg.Tags.Name or "Unknown"

  assert(contactPid, "Contact process ID is required")

  Contacts[contactPid] = contactName

  msg.reply({
    Tags = {
      Status = "Success",
      Contact = contactPid,
      Name = contactName
    }
  })
end)

-- ListContacts: Get all contacts
Handlers.add("ListContacts", "ListContacts", function(msg)
  local contactList = {}
  for pid, name in pairs(Contacts) do
    table.insert(contactList, { pid = pid, name = name })
  end

  msg.reply({
    Data = require('json').encode(contactList),
    Tags = {
      Count = tostring(#contactList)
    }
  })
end)

-- SendMessage: Send a message to another process
-- This uses Send() which writes to /results/outbox
-- The push@1.0 device delivers it to the target process
Handlers.add("SendMessage", "SendMessage", function(msg)
  local recipient = msg.Tags.Recipient
  local content = msg.Data or msg.Tags.Content

  assert(recipient, "Recipient is required")
  assert(content, "Message content is required")

  MessageCount = MessageCount + 1
  local messageId = tostring(MessageCount)

  -- Store in outbox
  table.insert(Outbox, {
    id = messageId,
    to = recipient,
    content = content,
    timestamp = msg.Timestamp or os.time()
  })

  -- Send to recipient via push@1.0
  -- This is delivered asynchronously by the push device
  Send({
    Target = recipient,
    Action = "ReceiveMessage",
    Tags = {
      ["Message-Id"] = messageId,
      Sender = ao.id,
      ["Sender-Name"] = Name
    },
    Data = content
  })

  msg.reply({
    Tags = {
      Status = "Sent",
      ["Message-Id"] = messageId,
      Recipient = recipient
    }
  })
end)

-- ReceiveMessage: Handle incoming messages (called by push@1.0)
Handlers.add("ReceiveMessage", "ReceiveMessage", function(msg)
  local messageId = msg.Tags["Message-Id"] or tostring(#Inbox + 1)
  local sender = msg.Tags.Sender or msg.From
  local senderName = msg.Tags["Sender-Name"] or "Unknown"
  local content = msg.Data

  -- Store in inbox
  table.insert(Inbox, {
    id = messageId,
    from = sender,
    fromName = senderName,
    content = content,
    timestamp = msg.Timestamp or os.time()
  })

  -- Optional: Send delivery confirmation
  Send({
    Target = sender,
    Action = "MessageDelivered",
    Tags = {
      ["Message-Id"] = messageId,
      Status = "Delivered"
    }
  })

  msg.reply({
    Tags = {
      Status = "Received",
      ["Message-Id"] = messageId
    }
  })
end)

-- GetInbox: Get all received messages
Handlers.add("GetInbox", "GetInbox", function(msg)
  msg.reply({
    Data = require('json').encode(Inbox),
    Tags = {
      Count = tostring(#Inbox)
    }
  })
end)

-- GetOutbox: Get all sent messages
Handlers.add("GetOutbox", "GetOutbox", function(msg)
  msg.reply({
    Data = require('json').encode(Outbox),
    Tags = {
      Count = tostring(#Outbox)
    }
  })
end)

-- Broadcast: Send message to all contacts
Handlers.add("Broadcast", "Broadcast", function(msg)
  local content = msg.Data or msg.Tags.Content
  assert(content, "Broadcast content is required")

  local sentCount = 0

  for pid, name in pairs(Contacts) do
    MessageCount = MessageCount + 1

    Send({
      Target = pid,
      Action = "ReceiveMessage",
      Tags = {
        ["Message-Id"] = tostring(MessageCount),
        Sender = ao.id,
        ["Sender-Name"] = Name,
        Type = "Broadcast"
      },
      Data = content
    })

    sentCount = sentCount + 1
  end

  msg.reply({
    Tags = {
      Status = "Broadcast-Sent",
      Recipients = tostring(sentCount)
    }
  })
end)

-- Ping: Health check - responds with Pong
Handlers.add("Ping", "Ping", function(msg)
  local requester = msg.From

  Send({
    Target = requester,
    Action = "Pong",
    Tags = {
      ["Original-Sender"] = requester,
      Responder = ao.id,
      ["Responder-Name"] = Name
    }
  })

  msg.reply({
    Tags = {
      Status = "Pong-Sent",
      To = requester
    }
  })
end)

-- Pong: Receive ping response
Handlers.add("Pong", "Pong", function(msg)
  local responder = msg.Tags.Responder or msg.From
  local responderName = msg.Tags["Responder-Name"] or "Unknown"

  msg.reply({
    Tags = {
      Status = "Pong-Received",
      From = responder,
      Name = responderName
    }
  })
end)

-- Info: Get messenger status
Handlers.add("Info", "Info", function(msg)
  local contactCount = 0
  for _ in pairs(Contacts) do contactCount = contactCount + 1 end

  msg.reply({
    Data = require('json').encode({
      name = Name,
      processId = ao.id,
      contacts = contactCount,
      inboxCount = #Inbox,
      outboxCount = #Outbox,
      totalMessages = MessageCount
    })
  })
end)
```

          { name: "Action", value: "AddContact" },

          { name: "Name", value: "Bob" },

    it("should add Alice as Bob's contact", async () => {

          { name: "Action", value: "AddContact" },
          { name: "Contact", value: alicePid },
          { name: "Name", value: "Alice" },
        ],
      })

      const result = await dryrun({
        process: bobPid,

      assert.equal(contacts.length, 1)
      console.log("Alice added to Bob's contacts")

        process: alicePid,
        signer: acc[0].signer,

          { name: "Action", value: "SendMessage" },

        tags: [
          { name: "Action", value: "ReceiveMessage" },

          { name: "Sender-Name", value: "Alice" },

        tags: [{ name: "Action", value: "GetOutbox" }],

import { describe, it, before, after } from "node:test"

const counterScript = readFileSync("counter.lua", "utf8")

describe("Counter App (HyperBEAM Beta3)", () => {

        },

    })
  })

### Understanding Beta3 Concepts

**Devices** are composable units that add functionality:

```
┌─────────────────────────────────────────────┐
│               Device Stack                   │
├─────────────────────────────────────────────┤
│  process@1.0    - Process management         │
│  scheduler@1.0  - Message scheduling         │
│  push@1.0       - Inter-process delivery     │
│  json-iface@1.0 - JSON interface             │
│  wasm-64@1.0    - 64-bit WASM execution      │
│  patch@1.0      - State patching             │
│  multipass@1.0  - Multi-pass execution       │
└─────────────────────────────────────────────┘
```

**HTTP Signatures** authenticate messages:

```javascript
// WAO handles signing automatically
const { slot } = await hb.schedule({
  pid,
  tags: { action: "Inc" },
})
// Internally creates HTTP-signature headers for beta3
```

**Slots** track message order:

```
Slot 0: Process spawn
Slot 1: Load script (Eval)
Slot 2: First Inc
Slot 3: Add 100
Slot 4: Dec
...
```
